## 📚 Learning Sources
- **Andrew Ng's Machine Learning Specialization** (Course 1: Supervised Machine Learning — 
  Regression and Classification) — DeepLearning.AI / Stanford Online, via Coursera. 
  Primary source for theory: cost functions, gradient descent, regularization.
- **Kaggle Intro to Machine Learning** — hands-on practice with decision trees, model 
  validation, underfitting/overfitting, random forests.
- **scikit-learn** — used throughout for actual implementation, paired directly with 
  concepts learned in Andrew Ng's course labs.
- **XGBoost documentation** — for gradient-boosted trees, covered later alongside 
  Random Forests (Oct 2026).
