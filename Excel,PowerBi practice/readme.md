## 📊 Excel

**Billionaire Dashboard 2025**
- KPI cards (Average Net Worth, Average Age, Billionaire Count)
- Combo chart (bar + line) showing net worth and age together
- Pivot-table-driven category breakdown (Technology, Fashion & Retail, Finance, etc.)
- Fully interactive slicers (Region, Self Made, Gender) linked across all visuals and tables

![Billionaire Dashboard Screenshot](./billionaire-dashboard-screenshot.png)

Skills practiced: Pivot Tables, slicers, KPI card design, combo charts, TRIM/PROPER for data cleaning, 
XLOOKUP concepts (via INDEX+MATCH, since local Excel is 2019), combining multiple sheets.
